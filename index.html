Welcome to github

Steps to setup github

  1. install git and create a github account
  2. configure your name and email in the git terminal (that is used in the commit metadata)
    git config --global user.name "your name"
    git config --global user.email "your email"

  3. To track and commit changes

    • to check status - git status
    • stage files -> add to staging area
      •     git add file_name //for a specific file
    git add . //for the whole current directory
    • for committing staged changes 
      •             git commit -m "initial commit"
  4. Add remote origin that will help git navigate the cloud repo
    5.             git remote add origin https://github.com/vishoov/example_project.git
